# Public Learning

Small tools and write-ups from building **The Old Gods**, a VR god game, with Claude. Each one is a single page you can open and play with.

Live at: https://somewhatrogue.github.io/Public_Learning/

## Labs

- **[Attack Feel Lab](https://somewhatrogue.github.io/Public_Learning/attack-feel-lab/)**: why combat feels choppy, and the five beats (gather, launch, travel, impact, aftermath) that fix it. Sixteen attacks with every timing on a slider, an Even vs Five beats toggle, a god-height view and real-world references for each beat.

Every page is a single self-contained HTML file: HTML, CSS and JavaScript drawing to a canvas. No build step, no server.
