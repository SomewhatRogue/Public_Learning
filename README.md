# Public Learning

How I build with Claude: when checking the real thing is slow, build a small lab first, agree on the core pieces there, then build it once. Each lab here is a single page you can open and play with, taken from making **The Old Gods**, a VR god game.

Live at: https://somewhatrogue.github.io/Public_Learning/

## Pages

- **[Build the lab first](https://somewhatrogue.github.io/Public_Learning/lab-first/)**: the pattern, and where it applies beyond games.

- **[Attack Feel Lab](https://somewhatrogue.github.io/Public_Learning/attack-feel-lab/)**: why combat feels choppy, and the five beats (gather, launch, travel, impact, aftermath) that fix it. Sixteen attacks with every timing on a slider, a one-minute guided tour, an Even vs Five beats toggle, a god-height view and real-world references for each beat.

Every page is a single self-contained HTML file: HTML, CSS and JavaScript drawing to a canvas. No build step, no server.
