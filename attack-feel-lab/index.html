Attack Feel Lab

Every attack in a game has five beats: gather, launch, travel, impact, aftermath. Speed comes from contrast between them, and impact comes from everything landing on one frame. This is the lab I built to tune the attacks in my VR god game, The Old Gods, without putting the headset on for every change. The starting values are the ones I approved.

What this lab is an example of

Decide before you build

Checking combat in the real game meant putting a VR headset on and off for every change. This page moves all of that iteration onto a flat screen, where a change takes a second. The game only gets built once the numbers are agreed. The same move works for almost anything with an expensive feedback loop. Read the pattern.
